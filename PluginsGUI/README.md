# PluginsGUI

このフォルダは、After Effects プラグイン向けの汎用 GUI データをまとめるための作業領域です。

## 目的

- 開発中/開発済みの GUI 設計資料を集約する
- CustomGraphEditor などの UI 実装資産を再利用しやすくする
- 各プラグイン固有コードと、GUI 共通資産を整理して分離する

## 配置方針

- プラグイン固有の実装コードは各 `plugins/<name>/` に置く
- 汎用 GUI データ（仕様メモ、座標系定義、入出力ルール、UI スモーク手順など）はこのフォルダに置く
- AE SDK / Drawbot 依存の具体実装は、必要に応じて個別実装側に残す

## 初期コンテンツ例

- `custom-graph-editor/`:
  - モデル/UI 接続仕様
  - イベントマッピング仕様
  - 座標変換ルール
  - 手動検証手順

必要に応じて、今後 GUI 種別ごとのサブフォルダを追加してください。
