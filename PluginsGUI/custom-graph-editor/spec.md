# Custom Graph Editor Spec

## 目的

- Custom Graph Editor の仕様を一元管理する
- Model 層と UI 層の責務境界を明確にする
- プラグイン実装時の判断ぶれを減らす

## スコープ

- 対象: UI 統合ロジック、描画仕様、入力仕様、座標変換仕様
- 非対象: AE SDK 依存の詳細実装、ホスト固有最適化、パフォーマンスチューニングの最適解

## データモデル前提

- `curve_editor::CurveEditorModel` を唯一の状態保持元とする
- UI 側は状態を複製せず、Model API 経由で更新する
- 不変条件（X 単調など）は Model 側に委譲する

## 描画仕様（正規化座標）

- 描画要素:
  - グリッド
  - ベジェ曲線ポリライン
  - アンカーポイント
  - イン/アウトハンドル
  - ハンドル接続線
- 画面描画直前に正規化座標 `[0,1]` から画面座標へ変換する

## 編集操作仕様

- アンカードラッグ: `MoveAnchor`
- インハンドルドラッグ: `MoveInHandle`
- アウトハンドルドラッグ: `MoveOutHandle`
- 曲線上クリックによるノード追加: `AddNodeOnCurve`
- アンカー削除（中間ノードのみ）: `RemoveNode`

## 今後の拡張候補

- スナップ（グリッド吸着）
- 複数選択
- ボックス選択
- Undo/Redo 統合
