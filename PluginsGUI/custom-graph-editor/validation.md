# Custom Graph Editor Validation

## 目的

- UI 統合後に最低限の操作が成立することを素早く確認する

## 事前条件

- Model 層がビルド済み
- UI アダプタが Model API を呼び出す配線済み
- 描画ループでグリッド/曲線/ノード/ハンドルを描画可能

## 検証手順

1. 初期表示
- グリッドが表示される
- 曲線が左下から右上へ描画される
- ノードが2点（始点/終点）で表示される

2. ノード追加
- 曲線上をクリック
- ノードが1点追加される
- 曲線が追加ノードを通る形で再描画される

3. アンカー移動
- 追加したノードをドラッグ
- ノード位置に追従して曲線が更新される
- 破綻（反転/NaN/飛び）が発生しない

4. ハンドル移動
- インハンドル/アウトハンドルをそれぞれドラッグ
- 曲線の曲率が変化する
- 不正な値で描画が崩れない

5. ノード削除
- 内部ノードに対して削除操作（Shift+Left または Right）
- ノードが削除され、曲線が再構成される
- 端点ノードは削除されない

## チェック観点

- すべての変更が Model API 経由で反映されている
- UI 側で不変条件ロジックを重複実装していない
- 画面座標 <-> 正規化座標の変換が一貫している

## メモ

- 本ドキュメントは手動確認用。必要に応じてスモークテストへ昇格させる。
