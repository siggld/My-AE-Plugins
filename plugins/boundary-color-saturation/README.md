# boundary-color-saturation ( TKG_BoundaryColorSaturation )

Creates boundary color extraction and blur control UI for compositing.

This is the After Effects plugin **TKG_BoundaryColorSaturation**, which provides the **BoundaryColorSaturation.aex** plugin file for Adobe After Effects.
